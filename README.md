# Zoo Applikation

## Mitglieder: Sebastian Willmann, Silvan Castelberg, Guy Neeman

# Projektname
Kurze Projektbeschreibung: Dieses Projekt basiert auf **Vite + React** und dient als Grundlage für eine moderne, schnelle Web‑Applikation.

## Voraussetzungen
- Node.js ≥ 18
- npm oder yarn

## Installation
```bash
npm install
# oder
yarn install
```

## Entwicklung starten
```bash
npm run dev
```
Das Projekt läuft standardmässig unter:  
**http://localhost:5173**

## Produktion bauen
```bash
npm run build
```

## Projektstruktur
```
src/
  components/
  pages/
  App.jsx
  main.jsx
public/
index.html
```

## Scripts
- `dev` – startet den lokalen Entwicklungsserver
- `build` – erstellt ein optimiertes Produktions‑Bundle
- `preview` – zeigt das gebaute Projekt lokal an
